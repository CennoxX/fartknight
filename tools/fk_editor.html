Fartknight Level Editor

Paint 16×12 maps for the TI-83+, write the poem, check that a level can be beaten, then copy the finished FKLVL source back to the calculator.

Levels

x –, y –
Playing: arrow keys move · Shift = 2ND · M = MODE (restart level, costs a life) · Esc = CLEAR (stop playing)
Click or drag to paint. Right-click paints floor. Start, key and exit move instead of duplicating. Keys: W . X K E G F B P T H and 1–4 for guards (down, left, right, up).

Poem

Up to 5 lines, 22 characters each. Shown between levels. AABA, hint at the level, never explain it.

Checks

    Test runs a full search with guard timing. The red trail shows the way out. If it runs out of room, try “Any route (faster)”.

    FKLVL source

    On the calculator: replace FKLVL, compile FKDATSRC, run FKDATA once. FKNIGHT reads the levels from the AppVar.
